# VANILLA renderer cost audit

The local `74ccbb5c` commit presents the SDK overlay. Its GPU time measures overlay presentation. Guest geometry and resolves reached Plume on October 13-14 (`6b14d66a`, `6014d336`, `5799de5b`), and `35970b6e` selected Plume by default on October 30. The historical GTX 1650 executable and backend need to match the owner's 4K60 observation before a gameplay bisect can use it.

The GTX 1650's 36.214 ms GPU interval at 1080p was Custom with class Mid, FSR 3.1 Native AA and Ultra mirrors. It is evidence for that workload. The 22 ms stock estimate based on transfer from the RTX 5080 is excluded. VANILLA holds the effect-page values in `src/gpu/gfx_preset.h`. DISPLAY and UPSCALING settings, UI sharpening and debug overrides can still change the workload.

The largest measured stock buckets above are the guest main draw and resolve conversions. Current VANILLA needs a matched workload comparison. The guest-byte pool preserves ordering across aliasing and partial writes. The reference pool check and lazy-encode design cover page ownership and write-watch setup that must occur before a later encode dispatch. The separate page-run implementation in `perf/LAZY-ENCODE.md` is a candidate to rebase after current pass and CPU measurements.

## Verification on this worktree

Nine standalone suites passed (27,158 checks). Tests covered frame order, G-buffer and screen demands, AO normals, RR guides, RT scene demand, diagnostics, and bloom selection/math. The diagnostic, RT and bloom tests caught 18 deliberately broken rules. Synthetic guest and two scaled bloom tap fixtures compiled to DXIL and SPIR-V, and all three SPIR-V modules passed validation. Their shader source in the actual pack is unchanged.

The nine changed renderer translation units passed targeted clang syntax checking against the pinned Plume and SDK headers, with generated host shader headers stubbed where needed. Exit audit passed for the renderer and debug menu. Settings exposure, row tags, menu rows, live readers and descriptor counts passed their audits.
