# Settings Renderer Advanced

Cvars of the two renderer implementations. Most are diagnostics, probes and tuning switches for development; none has a pause menu row except where the "Where" column says so. The main reference is [Settings Reference](Settings-Reference).

| Group | Cvars |
|---|---|
| Plume renderer, `src/gpu` | 48 |
| Legacy native runtime, `src/native_gfx` | 122 |

The pause menu offers renderers XENIA and NATIVE (the Plume renderer). The legacy runtime "is no longer offered" by the menu; a `larecomp.toml` that still selects it shows as XENIA (`src/mc_engine/pause_menu.cpp`). Its cvars are listed because they are still registered.

Table columns are described in [Settings Reference](Settings-Reference#how-to-read-the-tables).
