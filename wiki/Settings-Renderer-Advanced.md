# Settings Renderer Advanced

Cvars of the two renderer implementations. Most are diagnostics, probes and tuning switches for development; none has a pause menu row except where the "Where" column says so. The main reference is [Settings Reference](Settings-Reference).

| Group | Cvars |
|---|---|
| Plume renderer, `src/gpu` | 200 |
| Legacy native runtime, `src/native_gfx` | 122 |

The renderer (XENIA, or NATIVE, the Plume renderer) and the graphics API are no longer chosen in the pause menu: the launcher's Troubleshooting section sets them, and `--graphics_backend=auto|d3d12|vulkan` works on the command line. The legacy runtime is no longer offered at all; a `larecomp.toml` that still selects it shows as XENIA (`src/mc_engine/menus/pause_menu.cpp`). Its cvars are listed because they are still registered. Rows marked "Debug only." are tagged debug-only; see [Settings Reference](Settings-Reference#debug-menu).

Table columns are described in [Settings Reference](Settings-Reference#how-to-read-the-tables).
